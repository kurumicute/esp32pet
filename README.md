# 水伊布風格桌面時鐘寵物 (ESP32-S3 DeskPet)

一隻住在桌上的像素風水系寵物：顯示時間、日期、天氣、電量，會隨機眨眼、看左右、開心地跳；
可以直接換裝扮（也會依季節、生日自動換），閒置或晚上會睡覺，搖一搖會醒來，歪一邊會跟著看，
還有番茄鐘和手機網頁設定。音效**預設關閉**，可以在設定裡打開。

> 角色外觀參考寶可夢「水伊布」、「水晶燈火靈」、「達克萊伊」與 hololive「百鬼綾目」，屬於非官方同人創作，僅供個人使用，請勿商業販售或散布素材。

**角色切換**：內建三隻角色——水伊布、水晶燈火靈、達克萊伊（後兩隻會飄浮）；SD 卡可以再加（例如百鬼綾目貼圖角色）。活動選單 →「換角色」可即時預覽切換，手機網頁「角色與裝扮」卡片或序列埠 `char n` 也能換；所有動畫、裝扮、散步、摸頭都通用，選擇存在 NVS（`petChar`）。每隻角色有自己的叫聲與腳步聲：水伊布是原本的「咿～布！」，水晶燈火靈是低沉搖晃的幽靈聲（開心時加吊燈叮叮聲），飄著走所以腳步是輕輕的「咻」；達克萊伊是低沉沙啞的暗影低語（次諧波 + 氣音）；另有一組百鬼綾目用的高音「余～！」（給 SD 卡角色用 `--voice 3`）。

## 硬體

**Waveshare ESP32-S3-LCD-1.54**（icshop 368031700420，無觸控版）

| 項目 | 規格 / 腳位 |
|---|---|
| MCU | ESP32-S3R8，8MB PSRAM，16MB Flash |
| 螢幕 | 1.54" IPS，240x240，ST7789，SPI：DC=45 CS=21 SCK=38 MOSI=39 RST=40 BL=46 |
| 按鍵 | BOOT=GPIO0、PLUS=GPIO4、PWR=GPIO5（按下為 LOW） |
| 電源 | GPIO2 = 電池供電鎖定（程式開機時拉 HIGH）；電池電壓 GPIO1（1/3 分壓）；充電指示 GPIO3（LOW = 充電中） |
| 六軸感測器 | QMI8658，I2C SDA=42 SCL=41，位址 0x6B（搖晃、傾斜） |
| 音訊 | ES8311（I2C 0x18）+ 喇叭功放 GPIO7（HIGH = 開）；I2S MCLK=8 BCLK=9 LRCK=10 DOUT=12（官方 bsp_codec.c）。只在開啟音效時初始化；麥克風 ES7210 不使用 |

| RTC | **沒有**（I2C 掃描只找到 0x18 ES8311、0x40 ES7210、0x6B QMI8658）→ 斷電後時間要重新連網同步 |

腳位來源：Waveshare 官方範例 `ESP32-S3-LCD-1.54-demo/ESP-IDF-5.5.1/01_factory`。

## 燒錄

### Arduino IDE

1. 安裝 ESP32 開發板套件（Espressif Systems，測試版本 3.3.12）
2. 安裝函式庫 **GFX Library for Arduino**（測試版本 1.6.9；1.6.0 在核心 3.3.x 會編譯失敗）
3. 打開 `ESP32S3/ESP32S3.ino`，在「工具」選單設定：
   - 開發板：**ESP32S3 Dev Module**
   - USB CDC On Boot：**Enabled**
   - Flash Size：**16MB (128Mb)**
   - PSRAM：**OPI PSRAM**
   - Partition Scheme：**16M Flash (3MB APP/9.9MB FATFS)**（預設的 1.2MB 放不下）
4. 選擇連接埠，按上傳

### arduino-cli

```bash
arduino-cli compile --fqbn "esp32:esp32:esp32s3:CDCOnBoot=cdc,FlashSize=16M,PSRAM=opi,PartitionScheme=app3M_fat9M_16MB" --upload -p COM6 .
```

### 燒錄後沒反應？

這塊板子燒錄完自動重置時，偶爾會停在下載模式（螢幕全黑、序列埠沒輸出）。
**按一下 PWR 鍵或拔掉 USB 重插**即可；或執行：

```bash
esptool --port COM6 --before no-reset --after watchdog-reset chip-id
```

上傳失敗時：按住 BOOT → 插上 USB → 放開 BOOT，再上傳一次。

## 設定 Wi-Fi（時間同步）

Wi-Fi 帳密**不寫在程式碼裡**，存在板子的 NVS。有三種設定方式：

### 方式一：設定熱點（推薦，不用電腦）

板子**還沒設定 Wi-Fi，或連不上超過 60 秒**時，會自動開一個設定熱點，螢幕顯示：

1. 用手機連 Wi-Fi「`DeskPet-XXXX`」，密碼是螢幕上的 **8 位數字**（每次開熱點都不同）
2. 手機會**自動跳出設定頁**（沒跳出就用瀏覽器開 `http://192.168.4.1`）
3. 從清單選你家的 Wi-Fi（或自己輸入名稱）→ 輸入密碼 → 連線
4. 板子顯示「Wi-Fi 已連線！」，設定熱點約 20 秒後自動關閉

- 熱點開著時，若沒有手機連著，板子每 5 分鐘會用舊設定再試一次（例如路由器剛重開）；試連時熱點會短暫離開頻道，所以間隔刻意拉長，平常不自動重連
- 手機若曾連過同名熱點，可能自動帶入舊密碼而顯示密碼錯誤：先在手機上「忘記此網路」再輸入螢幕上的新密碼
- 已連線時用序列埠 `ap` 指令也能手動開熱點（3 分鐘後自動關）

### 方式二：手機網頁

板子已經連上網路時，主畫面長按 PLUS 看網址，在「Wi-Fi」區塊修改。

### 方式三：USB 序列埠

1. 打開 Arduino IDE 的序列埠監控視窗，鮑率 **115200**，換行設為「NL & CR」或「Newline」
2. 輸入 `wifi` → 依提示輸入 SSID → 再輸入密碼

連上後會自動用 NTP 同步台灣時間（UTC+8）。

其他序列埠指令：

| 指令 | 說明 |
|---|---|
| `status` | 時間、Wi-Fi、裝扮、電池、感測器、剩餘記憶體 |
| `wifi clear` | 清除 Wi-Fi 帳密 |
| `ap` | 立刻開設定熱點 |
| `ble clear` | 刪除 iPhone 藍牙配對 |
| `walk` | 開始 / 結束散步 |
| `char [n]` | 列出角色 / 切換角色（0 水伊布、1 水晶燈火靈、2 達克萊伊，3 以後 = SD 卡角色） |
| `sd` | SD 卡狀態與 /deskpet 底下各資料夾的檔案數 |
| `backup` / `restore` | 設定備份到 SD 卡 / 從 SD 卡還原 |
| `diary` | 印出日記 |
| `tap` | 開 / 關拍頭偵測除錯訊息（印出每次晃動的峰值） |
| `sound on` / `sound off` | 開 / 關音效（會存檔） |
| `sound` | 試聽一個音效 |
| `cry` | 叫一聲 |
| `song 0~3` | 音樂盒播放第幾首 |
| `rhythm` | 開始節奏遊戲 |
| `alarm test` | 立刻響鬧鐘（測試用） |
| `cwakey` | 設定中央氣象署 API 金鑰（空白 = 清除） |
| `county` / `county <n>` | 列出縣市 / 設定天氣縣市（7 = 臺中市） |
| `weather` | 天氣資料狀態 |
| `imu` | 重力向量（調整傾斜方向用） |
| `i2c` | 掃描板載 I2C 裝置 |

- 只支援 2.4GHz Wi-Fi
- 同步後就算 Wi-Fi 斷線，時鐘也會繼續走；斷電後要重新連網同步（板子沒有 RTC）

## 天氣（中央氣象署）

- 資料：開放資料 F-C0032-001（縣市 36 小時預報），每 30 分鐘更新，失敗 3 分鐘後重試
- 以 HTTPS 連線並用 ESP32 內建 CA 憑證包**驗證伺服器憑證**；在背景工作執行，不會卡畫面
- 金鑰到 https://opendata.cwa.gov.tw 申請，用 `cwakey` 指令或網頁設定，只存在板子 NVS，網頁不會顯示
- 主畫面左上角顯示天氣圖示與最低~最高溫；背景會跟著天氣變（見「互動與自動行為」）

## iPhone 通知

用 iOS 內建的藍牙通知服務（ANCS），**iPhone 不用裝任何 App**。

### 第一次配對

1. 確認設定裡「iPhone 通知」是**開**（預設開）
2. iPhone：**設定 → 藍牙**，在「其他裝置」點 **DeskPet**
3. 板子螢幕上方會出現 **6 位數配對碼**，在 iPhone 輸入
4. iPhone 問「允許 DeskPet 顯示你的通知？」→ 點**允許**
5. 板子顯示「iPhone 已連線！」就完成了；配對資料存在板子上，重開機不用重配

### 使用

- 新通知會在**上方時間區彈出 8 秒**：`[IG] 標題` + 最多 3 行內容，寵物會開心跳一下
- 常見 App 會顯示短名稱（IG、FB、LINE、Messenger、Discord、Threads、訊息、郵件…），其他顯示 App 代號
- 在其他畫面（設定、換裝…）收到的通知，回主畫面 60 秒內補顯示；**夜間睡眠時不打擾**
- 設定「通知內容」選**隱藏** → 只顯示 `[IG] 有新通知`，不顯示內容（隱私模式）
- emoji 會顯示成方框（像素字型沒有 emoji）

### 取消配對

板子：序列埠 `ble clear` 或網頁「取消 iPhone 配對」；**iPhone 也要到「設定 → 藍牙 → DeskPet → 忘記此裝置」**。

> 安全：配對需要輸入板子螢幕上的配對碼（防中間人），連線全程加密。通知內容只顯示在螢幕上，不會存檔或上傳。

## 手機網頁設定

主畫面**長按 PLUS** 看網址（`http://<板子IP>/` 或 `http://deskpet.local/`），手機要連同一個 Wi-Fi。
可以改所有設定項目（包括背景、天氣特效、溫度表情、省電）、天氣縣市與金鑰、Wi-Fi。

> ⚠️ 依需求**沒有密碼保護**：同一個網路的任何人都能修改設定（包括 Wi-Fi）。
> 網頁不會顯示 Wi-Fi 密碼和 API 金鑰，所有欄位在板子端檢查範圍，輸出有做 HTML 跳脫。
> 建議只在家裡信任的網路使用。

## 音效（預設關閉）

設定第 22 項「音效」打開（網頁「🔔 聲音」也可以），第 23 項調音量；切換時會試聽一聲。

> 規則：**自動音效**（下表）要「音效」開啟、而且醒著才會出聲；**你主動開的功能**（鬧鐘、音樂盒、節奏遊戲）一定有聲音。

| 什麼時候 | 聲音 |
|---|---|
| 摸頭 | 「啵～啵」，有時候會開心地叫「咿布咿！」 |
| 醒著的時候 | 每 10~25 分鐘「咿～布！」叫一聲（音高每次稍微不同） |
| 散步 | 腳步聲「噠、噠」；下雨天變成踩水聲 |
| 生日 | 自動播生日快樂歌 |
| 搖一搖 / 散步遇到蝴蝶 | 上揚三連音 |
| iPhone 通知 | 叮咚 |
| 番茄鐘專注 / 休息結束 | 小段旋律（同時螢幕閃爍） |
| 睡醒 | 打哈欠的叫聲 |
| 散步聞到花 / 換裝 | 亮晶晶音 |
| 整點 | 兩聲鐘聲（整點小動作開啟時）；早上 7 點叫一聲 |

- 睡覺、小睡時**一律不出聲**
- 音效用程式即時合成，沒有音檔；在背景播放，不會卡畫面
- 關閉時完全不初始化音訊晶片，喇叭功放保持關閉；開啟後功放只在播放時打開
- **不使用麥克風**（ES7210 不初始化、不收音）
- 開啟音效後晶片內部記憶體約多用 12KB（I2S 緩衝區 + 播放 task）；之後再關閉不會釋放，重開機才會

## 摸頭

這塊板子是**無觸控版**，螢幕不能偵測手指。摸頭有三種方式：

- **輕拍機器上方兩下**（1 秒內）：用板子上的 QMI8658 加速度計偵測。睡覺時拍兩下 = 叫醒
- 主畫面或散步時按 **BOOT**
- 網頁按「🤚 摸摸頭」

拍頭偵測的判斷方式：扣掉重力後的晃動量「先安靜 → 突然變大 → 0.12 秒內又安靜」算一下輕拍。
持續晃動（拿起來、搖晃）不算拍，照舊交給搖晃偵測；按按鍵前後 0.4 秒也不算（按鍵會讓板子震一下）。
靈敏度在設定第 21 項「拍頭偵測」調整（關 / 低 / 中 / 高）。拍了沒反應或常常誤判時，
用序列埠輸入 `tap`，每次晃動都會印出 `[tap] peak 0.23g 40ms TAP` 這樣的紀錄，可以依峰值調整。
一隻手會在頭上拍三下，寵物瞇眼、冒出愛心，下方輪流顯示「好舒服～」等一句話；次數會記進日記。

## 鬧鐘

設定第 24~27 項（或網頁「⏰ 鬧鐘」）：開關、幾點、幾分（每次 5 分）、每天 / 平日 / 週末。

- 響鈴前 15 分鐘，夜間睡眠中的螢幕會從最暗慢慢亮起來（晨光）
- 時間到：上方顯示「⏰ 07:00 起床囉！」，每 3.5 秒響一次鈴聲，寵物跳起來；響 3 分鐘沒人理會自己停
- **中鍵 = 關閉**；**左 / 右鍵或拍兩下 = 再睡 5 分鐘**
- 鬧鐘一定有聲音（不受「音效」開關影響），叫醒後 30 分鐘內寵物不會回去睡
- 限制：鬧鐘設在 00:00~00:14 時，晨光不會在前一天晚上開始

## 節奏遊戲

活動選單 →「節奏遊戲」。節拍器以 96 BPM「噠、噠」，先 4 拍預備（3、2、1、開始！），接著 32 拍：
跟著拍子按**左 / 右鍵**或**輕拍板子一下**。下方軌道上的圓點走到左邊的圈圈時就是拍點。

- 差 0.09 秒內「好棒！」，0.16 秒內「不錯～」，寵物會開心跳一下；太早 / 太晚會提示
- 結束顯示「跟上了 N / 32 拍」，沒有排行、獎勵或解鎖
- 為了拍子準，遊戲中喇叭會持續輸出（送靜音），延遲固定約 0.09 秒並已補償

## 音樂盒

活動選單 →「音樂盒」：生日快樂、小星星、兩隻老虎、小蜜蜂（傳統兒歌旋律），八音盒音色，寵物會跟著跳。

## 散步模式

主畫面**長按 PLUS** → 活動選單 →「散步」（或網頁按「帶牠去散步」、序列埠 `walk`）。

- 寵物在中間一步一跳往前走，草地往左捲動（天空和遠山不動）；上方顯示經過時間和步數
- 路上隨機遇到：**路邊的花**（停下來聞一聞）、**蝴蝶**（在頭上飛一陣子）、**坐下休息**
- 只是散步的小插曲：不收集、不解鎖、沒有獎勵，次數只會寫進當天日記
- 按 PWR 回家；走滿 30 分鐘會自己回家。散步中不會小睡或進入夜間睡眠

## 每日小日記

主畫面**長按 PLUS** → 活動選單 →「日記」（網頁最下方也看得到，序列埠 `diary` 可印出）。

每天自動記錄：天氣與溫度、散步次數 / 分鐘 / 步數、聞了幾朵花、看到幾隻蝴蝶、被摸摸、被搖晃、專注完成幾輪、收到幾則通知（**只記則數，不記內容**）、打盹次數、換裝與當天的裝扮，再組成幾句話，例如：

> 天氣晴時多雲，27~31°C。去散步 1 次，共 12 分鐘、2400 步。路上聞了 2 朵花，看到 1 隻蝴蝶。被摸摸 5 次，好開心～ 今天是超棒的一天！

- 保留**最近 7 天**，存在 NVS（重開機不會不見）；換日時馬上存，平常最多 10 分鐘寫一次，關機前也會存
- 時間還沒同步前的紀錄先放在記憶體，同步後併入今天

### 傾斜方向不對？

感測器軸向需要實機確認。如果寵物看的方向跟你歪的方向**相反**，把 `src/config/BoardConfig.h` 的
`TILT_SIGN` 改成 `-1`；如果左右歪都沒反應、前後傾才有反應，把 `TILT_AXIS` 改成 `1`。可用 `imu` 指令看數值。

## SD 卡（選用）

TF 卡槽是 SDMMC 4-bit（GPIO 16/15/17/18/13/14，來源：Waveshare 官方 `07_sd_card_test`）。開機掛載一次，**沒插卡時以下功能全部自動略過**。
卡片用 FAT32 / exFAT，資料都在 `/deskpet/`（第一次開機會自動建資料夾）。用 `tools/sdcard.py` 準備檔案（輸出到專案的 `sdcard/`），再用下面任一方式放進卡片：

- **Wi-Fi 上傳（不用拔卡）**：`python tools/sdcard.py push --host <板子 IP>`，或手機網頁「SD 卡 → 上傳」。限角色 / 照片 / 歌曲 / 音效，副檔名、檔名、大小都會檢查，先寫暫存檔再改名；角色與歌曲馬上重新載入，音效要重開機。網頁沒有密碼，所以**韌體更新檔不開放網頁上傳**。
- **拔卡複製**：把 `sdcard/` 整個複製到卡片根目錄（或 `--out E:\` 直接寫卡）。韌體更新檔只能用這個方式。


| 功能 | 卡片上的位置 | 準備方式 |
|---|---|---|
| **更多角色** | `chars/*.dpc` | 像素角色：`python tools/sdcard.py char <assets/pets 底下的資料夾> --name 名稱 --voice 0~3`；貼圖角色（一張單色背景的 Q 版圖，自動去背縮圖，只會上下浮動；裝扮對齊點依 Q 版比例估計，可用 `--head/--eyes/--neck` 微調，`--no-costume` = 不穿裝扮〔檔頭 voice 最高位 0x80〕）：`python tools/sdcard.py sticker 圖.png --folder ayame --name 百鬼綾目 --voice 3`；開機載入 PSRAM，接在內建角色後面（最多共 16 隻），不用重新燒錄 |
| **相框** | `photos/*.565`（240x240 RGB565） | `python tools/sdcard.py photo a.jpg b.png …`；活動選單 →「相框」，每 10 秒自動換 |
| **日記長期保存** | `diary/YYYYMM/DD.txt` | 自動：日記每次存檔（10 分鐘 / 換日）就寫一份；第一行是統計 CSV，後面是日記句子。網頁 `/history` 依月份瀏覽、下載 CSV |
| **音樂盒自訂歌曲** | `music/*.wav` | `python tools/sdcard.py music 歌.wav`（轉 16kHz 單聲道）；檔名 = 歌名，中文可以；從 SD 卡串流播放 |
| **自訂音效** | `sound/<角色資料夾>/<名稱>.wav`、`sound/common/<名稱>.wav` | `python tools/sdcard.py sound x.wav --as cry [--char darkrai]`；開機讀進 PSRAM，最長 3 秒；角色專屬 > 共用 > 內建合成 |
| **紀錄與圖表** | `log/YYYYMMDD.csv` | 自動：時間同步後每 10 分鐘一行（電量、電壓、充電、Wi-Fi 訊號、今天累計摸頭 / 搖晃、角色、天氣）。網頁 `/stats` 畫電量曲線與每小時摸頭次數 |
| **設定備份 / 還原** | `backup/settings.txt` | 網頁「SD 卡」卡片或序列埠 `backup` / `restore`；**不含 Wi-Fi 密碼與 API 金鑰** |
| **SD 卡更新韌體** | `update/firmware.bin` | `python tools/sdcard.py firmware <build>/ESP32S3.ino.bin`；插卡開機自動寫入另一個 OTA 分割區、改名成 `firmware.done` 後重開機（失敗改名 `firmware.failed`） |

> ⚠️ 用 SD 卡更新過韌體後，開機分割區會變成 app1。之後用 USB 燒錄時要連 `boot_app0.bin`（0xe000）一起寫，`arduino-cli upload` 會自動處理；只寫 0x10000 會沒有作用。

## 中文字型

使用 **俐方體 11 號（Cubic 11）** 像素字型（`assets/fonts/`，授權見 `OFL.txt`，可自由使用與散布）。
韌體收錄字型裡的**全部 31,741 個字**（中日文、標點、全形符號，約 900KB），所以 iPhone 通知等任意文字都能顯示；只有 emoji 會顯示成方框。
字型檔或 `src/ui/Strings.h` 有變動時執行 `python tools/gen_font.py`。

### 設計重點

- 主要物件靜態配置；大型畫面緩衝區開機時一次配置在 PSRAM，把晶片內部記憶體留給 Wi-Fi / 藍牙 / HTTPS
- 網頁用固定緩衝區分段輸出（WebServer / HTTP / 藍牙函式庫內部仍有少量動態配置）
- 記憶體實測（Wi-Fi + 藍牙 + 天氣同時運作）：內部剩約 140KB，HTTPS 連線時最低約 72KB；`status` 指令可查
- 主迴圈不阻塞：動畫、時鐘、Wi-Fi 都用 `millis()` 計時；天氣在獨立工作抓取
- 局部更新：時間只在分鐘改變時重畫，冒號單獨閃爍；寵物區只在影格改變時推送 128x136 的區塊
- 只使用一套 LCD 驅動（Arduino_GFX，也是 Waveshare 官方範例使用的）
